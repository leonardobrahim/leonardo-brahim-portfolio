# 🎨 Leonardo Brahim | Portfolio

Este é o repositório do meu portfólio pessoal, que combina uma estética **Neo-Brutalista** vibrante com toques de **ilustração Cartoon**. O projeto foi construído para ser moderno e responsivo, destacando minha trajetória como desenvolvedor frontend.

## 🚀 Sobre o Projeto

O design utiliza elementos marcantes do Neo-Brutalismo, como sombras sólidas, bordas grossas e cores de alta vibração, misturados a uma temática lúdica de cartoons e stickers.

### Principais Funcionalidades:

- **Tema Dark/Light**: Alternância de cores com persistência de estado.
- **Design Neo-Brutalista**: Sombras pretas sem desfoque e bordas bem definidas.
- **Estética Cartoon**: Uso de avatares estilizados, componentes de "adesivos" e elementos visuais flutuantes.
- **Animações Fluídas**: Transições e interações dinâmicas via Framer Motion.

## 🛠️ Tech Stack

As principais tecnologias utilizadas no desenvolvimento foram:

- **React 19** & **TypeScript**
- **Tailwind CSS** (Estilização e Dark Mode)
- **Framer Motion** (Animações)
- **Lucide React** (Ícones)
- **Vite** (Build tool)

## 💻 Como Rodar Localmente

1.  **Instale as dependências:**
    ```bash
    npm install
    ```
2.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm run dev
    ```
